
# Nekron-libs

A set of ready-to-use tools across various domains that enable developers to build their applications more securely and simply, with tested code that is easily extensible and significantly reduces development time.


## Features

- Manage files and folders
- Create log files and print logs in terminal
- Create system notifications
- Access encryption / decryption algorithms
- Swing dialogs, messages and form utilities
- Access software and hardware information
- Print text, tables and interperate commands in terminal
- Easily manage text files (read, write, search, etc...)


## Deployment

For compile and installing project use maven build system

Compile and build project
```powershell
  mvn clean package
```
Install project into local repository
```powershell
  mvn clean install
```
